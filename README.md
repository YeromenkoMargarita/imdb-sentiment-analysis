# IMDB Sentiment Analysis

## Про проєкт
Цей проєкт присвячений автоматичній класифікації емоційного забарвлення англомовних кіновідгуків з датасету IMDB(https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews/suggestions). Основна мета - порівняти ефективність класичних моделей машинного навчання: логістичної регресії та наївного байєсівського класифікатора.

## Дані
* **Обсяг вибірки:** 5 000 записів.
* **Розбиття:** 80% для навчання (4 000 відгуків) та 20% для тестування (1 000 відгуків).

## Обробка даних
* **Очищення тексту:** Видалення HTML-тегів та пунктуації, нормалізація тексту.
* **Векторизація:** Перетворення слів у числа за допомогою `TfidfVectorizer`[cite: 2].
* **Оптимізація:** Свідоме обмеження словника до 5000 найбільш значущих ознак для уникнення переповнення оперативної пам'яті під час роботи з розрідженими матрицями.

## Стек технологій
* **Мова:** Python.
* **Бібліотеки:** `pandas` для маніпуляцій з табличними даними, `scipy` для зберігання числових векторів, `scikit-learn` для побудови моделей.

## Результати
* **Logistic Regression (Логістична регресія):** F1-score = **85,60%**.
* **Multinomial Naive Bayes (Наївний Байєс):** F1-score = **81,90%**.

**Висновок:** Логістична регресія продемонструвала кращий результат завдяки здатності враховувати нечіткість та розпізнавати нелінійні залежності у вагах ознак. Наївний Байєс виявився менш ефективним через припущення про абсолютну незалежність слів.
